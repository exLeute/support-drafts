# Підключення джерел даних

Звітко підтримує PostgreSQL, MySQL, BigQuery, Google Sheets та завантаження файлів CSV.

1. Перейдіть у «Налаштування» → «Джерела даних» → «Додати джерело».
2. Виберіть тип і введіть параметри підключення. Для баз даних рекомендуємо окремого користувача лише з правами на читання.
3. Натисніть «Перевірити з'єднання», потім «Зберегти».

Якщо з'єднання не встановлюється, додайте IP-адреси Звітко 203.0.113.10 і 203.0.113.11 у білий список вашого сервера.
Дані з джерел оновлюються кожну годину; частоту можна змінити в налаштуваннях джерела (тариф «Бізнес» — до 5 хвилин).
